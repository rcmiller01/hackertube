# Privacy policy

The canonical, shipped [privacy policy and terms](../../hackertube/hackertube_core/privacy-policy.txt) is versioned in `hackertube_core/privacy.py`. It is served through the local plugin’s `/privacy` endpoint before agreement and is available through Privacy on every page. It requires renewed agreement when the version changes. This document links the actual product copy instead of maintaining a second draft.

The GitHub link becomes publicly readable when publication is separately authorized. Local installations already include the full policy; they do not depend on public GitHub access to read or accept it.
