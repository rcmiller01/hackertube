## Ownership and regression coverage

The two stored API-metadata copies are retrieved_catalog and search_result. One ProfileStore boundary cleans both on opening and transactional metadata access; it sanitizes expired response content, interpretations and explanations while retaining numeric usage/job summary and independent library state. The earliest original metadata/source/job time governs aged response expiry, so a later search cannot renew old metadata.

Attribution enumeration: two Python display writers now use one destination-aware helper; the frontend's seven source-name calls pass their item through its shared helper, and the source-control policy names both stores. Open Library has two production dispatch paths (explicit Search and legacy refresh), both using its single header helper. The private contact is not a query parameter, shared header default, result field or plugin-data value.

The source-fix PR changes runtime behavior; after review/merge, repin the catalog, validate that exact commit, and refresh the demo/gallery as needed. The current PR #20 video is honest evidence for the prior merged build and is not relabeled as the unmerged source fixes.
