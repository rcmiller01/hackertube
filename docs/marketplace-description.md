# Prepared marketplace description

Historical draft for catalog pin `026b3d7`. The newer [hard-stop candidate](search-execution.md) is verified separately and needs review/repinning before this release copy changes.

HackerTube brings source-backed media discovery to the Hermes dashboard. Ask a focused question, choose a provider you already configured in Hermes, and discover videos, podcasts, books, and audiobooks. Search retrieves fresh records, applies requested formats and time limits, balances categories, and explains model relevance. Save results in a profile-local library and open the originals at their sources.

Ordinary browsing and library actions make no model or search call. Explicit Search can use model credits and source quota; usage is shown and unreported cost stays unknown. Search has a 45-second work budget, 12 logical provider requests, and 24 results. In-flight host retries are not forcibly cancelled. Missing credentials and partial coverage are disclosed. Media is linked, not hosted or played.

Supported discovery paths include Hacker News, Apple/iTunes, Open Library, LibriVox, optional YouTube Data API and Podcast Index, and Hermes web search when available. Reddit remains disabled pending approval. The small seed is development content, with no curated community endorsements; model relevance is not a community recommendation. Source release checks remain open.

**Andrej Karpathy created the original HackerTube and inspired this project.** Read his [original HackerTube post](https://karpathy.bearblog.dev/hacker-tube/) and visit [hackertube.org](https://hackertube.org/).

This is an independent Hermes adaptation. Prepared copy only; this listing has not been published.
