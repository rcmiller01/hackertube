# Proposed source matrix

Researched November 5, 2026. These sources are proposed, not implemented or approved for unrestricted reuse. "Documented" means an official page was read. It does not mean that HackerTube has credentials, provider approval, or a working adapter. Re-check the terms when implementation starts and before release.

## Defaults and community scope

Hacker News is the default community. Its proposed access method is the Algolia HN Search API. Karpathy's [HackerTube post](https://karpathy.bearblog.dev/hacker-tube/) verifies that his project downloaded Hacker News comments, selected YouTube recommendations, and used the YouTube API for metadata. The post does not identify Algolia, so this access-method resemblance is not verified.

Reddit is a second community source only for user-selected subreddits. The plugin never queries all of Reddit for discovery. Proposed starting subreddits are `r/programming`, `r/technology`, `r/books`, `r/audiobooks`, and `r/podcasts`. These are candidates for Robert's review, not evidence that each subreddit permits automated use. Users can replace them. Private, quarantined, banned, or unavailable subreddits stay disabled with a visible error.

A catalog source and a community-evidence source have different jobs. YouTube, Apple, Podcast Index, Open Library, and LibriVox identify media. A link repeated by Hacker News or a selected subreddit is community evidence only when the retrieved discussion supports an endorsement.

## Reddit verified versus unresolved

Documented official requirements are OAuth registration, explicit access approval, truthful identification, subreddit-and-action minimization, the 100-QPM free access limit, and compliance with deletion, retention, attribution, and content-owner restrictions. HackerTube can submit retrieved content for relevance classification only if its approved use case permits that processing. The Data API Terms do not grant a general right to train a model, so model training is prohibited.

Unresolved items are whether Nous or individual users count as commercial operators for the planned distribution, whether Reddit approves this recommendation use case, which OAuth grant and Hermes credential binding to use, and the exact fields or excerpts the approval allows the plugin to store. The default subreddit list is also unreviewed. Reddit stays disabled until those questions have answers.

## Hermes credential and update constraints

The [catalog-submission guide](https://hermes-agent.nousresearch.com/docs/developer-guide/plugins/catalog-submission) requires public HTTPS cloning, review at an exact commit, public extension interfaces, matching declared capabilities, and disclosure of network and storage behavior. Credentials must use a declared `requires_env` or secret `config_schema` entry and Hermes secret scope, or a declared OAuth route. A plugin cannot read `.env`, `auth.json`, another tool's login, a browser profile, or a keychain directly. Plugin data is not a permitted alternative secret store. Catalog builds cannot self-update; a new reviewed SHA-bump PR distributes updates.
